# The Evolution of LEGO (1975–2025)

## Overview

A data analytics project exploring 50 years
of LEGO sets, themes, minifigures and colors.

## Objectives

- Analyze historical LEGO production trends.
- Investigate product complexity.
- Explore theme evolution.
- Analyze minifigure distribution.
- Study color diversity.

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- SQL
- Power BI

## Project Status

Environment setup and data exploration.
